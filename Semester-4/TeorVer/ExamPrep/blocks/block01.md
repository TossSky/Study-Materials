## Вопрос 1. Основные понятия. Событие. Операции над событиями. Вероятностное пространство. Аксиомы. Дискретное вероятностное пространство. Классическое определение вероятности

*Эксперимент* — ситуация с более чем одним возможным исходом, из которых всегда наступает ровно одно *элементарное событие* $\omega_i$. Множество $\Omega = \{\omega_i\}$ — *пространство элементарных событий*; $A \subseteq \Omega$ — *событие*; $\Omega$ — достоверное событие, $\varnothing$ — невозможное.

**Операции над событиями.** $A \cup B = \{\omega \mid \omega \in A$ или $\omega \in B\}$ — объединение; $A \cap B = \{\omega \mid \omega \in A$ и $\omega \in B\}$ — пересечение; $A \setminus B = \{\omega \mid \omega \in A,\ \omega \notin B\}$ — разность; $\bar{A} = \Omega \setminus A$ — противоположное событие. Запись $A \subset B$ означает, что $A$ влечёт за собой $B$; события несовместны, если $A \cap B = \varnothing$.

**Определение.** *Алгебра* — совокупность $S$ подмножеств множества $M$, для которой: 1) $M \in S$; 2) $\forall\, M_1, M_2 \in S$ выполнено $M_1 \cup M_2 \in S$ и $M_1 \setminus M_2 \in S$. *$\sigma$-алгебра* — алгебра, содержащая объединение любого счётного числа своих элементов.

**Аксиомы для $\sigma$-алгебры событий $\mathcal{F}$:** 1) $\Omega \in \mathcal{F}$; 2) $A \in \mathcal{F} \Rightarrow \bar{A} \in \mathcal{F}$; 3) $A_n \in \mathcal{F} \Rightarrow \bigcup_n A_n \in \mathcal{F}$.

**Аксиомы вероятности.** Функция $P\colon \mathcal{F} \to \mathbb{R}$ называется вероятностью, если: 1) $0 \le P(A) \le 1$ для всех $A \in \mathcal{F}$ (неотрицательность); 2) $P(\Omega) = 1$ (нормированность); 3) для попарно несовместных $A_n$ выполнено $P\!\left(\bigcup_n A_n\right) = \sum_n P(A_n)$ (счётная аддитивность). Тройка $(\Omega, \mathcal{F}, P)$ — *вероятностное пространство* (А. Н. Колмогоров, 1933).

**Дискретное вероятностное пространство.** $\Omega$ конечно или счётно, $\mathcal{F} = 2^{\Omega}$; задаются веса $p_i = P(\omega_i) \ge 0$ с условием $\sum_i p_i = 1$, и $P(A) = \sum_{\omega_i \in A} p_i$.

**Классическое определение.** Если $\Omega$ конечно, а исходы равновозможны, то $P(A) = m/n$, где $n = |\Omega|$ — общее число исходов, $m = |A|$ — число благоприятствующих $A$.

## Вопрос 2. Свойства вероятностей. Формула включения-исключения

Пусть $(\Omega, \mathcal{F}, P)$ — вероятностное пространство, $A, B \in \mathcal{F}$.

1. $P(A) = 1 - P(\bar{A})$.
   *Доказательство.* $A \cup \bar{A} = \Omega \Rightarrow P(A \cup \bar{A}) = 1$; при этом $A \cap \bar{A} = \varnothing \Rightarrow P(A \cup \bar{A}) = P(A) + P(\bar{A})$. Следовательно, $P(A) + P(\bar{A}) = 1$. $\square$
2. $P(A) = P(A \setminus B) + P(A \cap B)$, так как $A = (A \setminus B) \cup (A \cap B)$ — объединение несовместных событий.
3. Монотонность: если $A \subseteq B$, то $P(A) \le P(B)$.
4. $P(A \cup B) = P(A) + P(B) - P(A \cap B)$.

**Формула включения-исключения.** Положим
$$P_1 = \sum_i P(A_i),\quad P_2 = \sum_{i<j} P(A_i \cap A_j),\quad \ldots,\quad P_n = P\!\left(\bigcap_{k=1}^{n} A_k\right).$$
Тогда
$$P\!\left(\bigcup_{k=1}^{n} A_k\right) = P_1 - P_2 + \cdots + (-1)^{n-1} P_n.$$

**Пример** (задача о совпадениях). На экзамене $n$ билетов; каждый из $n$ студентов выучил один билет и берёт случайный. Пусть $A_k = \{k$-й студент взял $k$-й билет$\}$, тогда $A = \bigcup_{k=1}^n A_k$ — хотя бы один взял «свой». Для пересечения $s$ событий $P(A_{k_1} \cap \cdots \cap A_{k_s}) = \tfrac{(n-s)!}{n!}$, число таких слагаемых равно $C_n^s$, поэтому $P_s = C_n^s \cdot \tfrac{(n-s)!}{n!} = \tfrac{1}{s!}$. Отсюда
$$P(A) = 1 - \frac{1}{2!} + \frac{1}{3!} - \cdots \pm \frac{1}{n!} \;\xrightarrow[n\to\infty]{}\; 1 - e^{-1}.$$

## Вопрос 3. Условная вероятность. Свойства условной вероятности. Формула умножения вероятностей

**Определение.** *Условная вероятность* события $A$ при условии, что наступило событие $B$ (где $P(B) > 0$):
$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}.$$

**Свойства.** Условная вероятность $P(\,\cdot \mid B)$ сама является вероятностью на $\mathcal{F}$: 1) $0 \le P(A \mid B) \le 1$; 2) $P(\Omega \mid B) = P(B \mid B) = 1$; 3) для попарно несовместных $A_n$ выполнено $P\!\left(\bigcup_n A_n \mid B\right) = \sum_n P(A_n \mid B)$.

**Формула умножения вероятностей.** Из определения $P(A \cap B) = P(B)\,P(A \mid B) = P(A)\,P(B \mid A)$. По индукции для $n$ событий:
$$P\!\left(\bigcap_{k=1}^{n} A_k\right) = P(A_1)\,P(A_2 \mid A_1)\,P(A_3 \mid A_1 \cap A_2)\cdots P(A_n \mid A_1 \cap \cdots \cap A_{n-1}).$$

## Вопрос 4. Независимые события. Попарно и взаимно независимые события. Теорема о замене событий на противоположные

**Определение.** Событие $A$ не зависит от $B$, если $P(A \mid B) = P(A)$. Это равносильно условию $P(A \cap B) = P(A)\,P(B)$ (симметричному по $A$ и $B$); тогда события $A$ и $B$ называются *независимыми*.

События $A_1, \ldots, A_n$ *попарно независимы*, если $P(A_i \cap A_j) = P(A_i)P(A_j)$ для всех $i \ne j$.

События $A_1, \ldots, A_n$ *взаимно независимы* (независимы в совокупности), если для любого поднабора индексов вероятность пересечения равна произведению вероятностей:
$$P(A_{i_1} \cap \cdots \cap A_{i_m}) = P(A_{i_1})\cdots P(A_{i_m}),\qquad 2 \le m \le n.$$
Взаимная независимость сильнее попарной.

**Теорема.** Если в наборе взаимно независимых событий $A_1, \ldots, A_n$ все или часть заменить противоположными, то взаимная независимость сохраняется.

*Доказательство* (для $n = 2$).
$$P(\bar{A}_1 \cap \bar{A}_2) = P(\overline{A_1 \cup A_2}) = 1 - P(A_1 \cup A_2) = 1 - P(A_1) - P(A_2) + P(A_1)P(A_2) =$$
$$= (1 - P(A_1))(1 - P(A_2)) = P(\bar{A}_1)\,P(\bar{A}_2). \qquad \square$$

## Вопрос 5. Полная система событий. Формула полной вероятности. Формула Байеса

**Определение.** Набор $H_1, H_2, \ldots \in \mathcal{F}$ — *полная система (полная группа) событий*, если 1) $\bigcup_i H_i = \Omega$ и 2) $H_i \cap H_j = \varnothing$ при $i \ne j$.

**Теорема (формула полной вероятности).** Пусть $H_1, H_2, \ldots$ — полная система, $A \in \mathcal{F}$. Тогда
$$P(A) = \sum_k P(A \mid H_k)\,P(H_k).$$
*Доказательство.* $A = A \cap \Omega = A \cap \left(\bigcup_k H_k\right) = \bigcup_k (A \cap H_k)$. События $A \cap H_k$ попарно несовместны, поэтому
$$P(A) = \sum_k P(A \cap H_k) = \sum_k P(A \mid H_k)\,P(H_k). \qquad \square$$

**Формула Байеса.** Если произошло событие $A$ ($P(A) > 0$), то апостериорные вероятности гипотез:
$$P(H_i \mid A) = \frac{P(A \mid H_i)\,P(H_i)}{\sum_k P(A \mid H_k)\,P(H_k)}.$$
Здесь $P(H_i)$ — априорные вероятности (до опыта), $P(H_i \mid A)$ — апостериорные (после опыта).

**Пример.** Около $40\%$ компьютеров собрано из высококачественных деталей; надёжность за время $t$ равна $0{,}97$ для качественных и $0{,}75$ для обычных. Компьютер проработал безотказно — найти вероятность, что он из качественных. Гипотезы: $H_1$ (качественные), $P(H_1) = 0{,}4$; $H_2$ (обычные), $P(H_2) = 0{,}6$; событие $A = \{$безотказная работа$\}$, $P(A\mid H_1) = 0{,}97$, $P(A\mid H_2) = 0{,}75$. По формуле Байеса
$$P(H_1 \mid A) = \frac{0{,}97 \cdot 0{,}4}{0{,}97 \cdot 0{,}4 + 0{,}75 \cdot 0{,}6} \approx 0{,}463.$$
