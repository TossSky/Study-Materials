## Правила оформления (строго)
1. Пиши **только фрагмент** — без `\documentclass`, преамбулы, `\begin{document}`. Начинай сразу с `\section*{...}`.
2. Каждый вопрос:
   ```
   \section*{Вопрос N. <краткий заголовок>}
   \addcontentsline{toc}{section}{Вопрос N. <очень краткий заголовок для оглавления>}
   ```
3. **Минимум текста.** Только: определения, ключевые формулы, короткие доказательства (1–2 строки) там, где они принципиальны и есть в лекции. Без примеров, без вводных фраз, без «важно отметить», без воды.
4. **Перечисления — только списками столбиком** через `\begin{enumerate}...\end{enumerate}` или `itemize`. НИКОГДА не пиши «1) … 2) … 3) …» в одну строку.
5. Формулы: в тексте `$...$`; выносные `\[ ... \]`; многострочные выкладки — `align*` (или `aligned`).
6. Доказательство оформляй так, чтобы значок конца стоял в КОНЦЕ строки:
   `\textit{Док-во:} ... \hfill$\square$` (НЕ ставь `$\square$` отдельным абзацем — он соскочит на новую строку).
7. Минимум жирного. Термины — `\textit{...}`. Маркеры «Определение/Теорема/Док-во» — `\textit{...}`. `\textbf` использовать редко.
8. Доступные команды: `amsmath`, `amssymb` (`\mathcal`, `\mathbb`, `\varnothing`, `\bigcup`, `\bigcap`, `\sum`, `\prod`, `\frac`, `\binom`, `\xrightarrow`, `\square`, `\sim`, `\to`, `\infty`, `\le \ge \ne`, `\Rightarrow`, греческие). Пакеты не подключай. Не используй `\boxed`.
9. Десятичные дроби — через запятую в виде `0{,}5`. Кавычки русские «ёлочки» или прямые.
10. Русский язык, кириллица — пиши обычным текстом (шрифт её поддерживает).
